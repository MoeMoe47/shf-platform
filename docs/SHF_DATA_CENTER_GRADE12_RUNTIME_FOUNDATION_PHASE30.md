# SHF Data Center Grade 12 Runtime Foundation

Phase 30 activates one bounded Grade 12 reference slice. The active course is
`data-center-technical-operations-12`; it contains the five small common-core
lessons and the Technical Operations advanced lessons. It requires the
`grade12-entry-v1` eligibility result and an authorized course assignment.

The planned capstone, `Build Ohio's Next AI Data Center`, and the other five
Grade 12 branches remain non-executable. The capstone contract is hybrid:
generic Projects own teams and versioned submissions, while generic
Prepare/Prove owns individual results, evidence, and competency decisions.

## Runtime boundaries

- Course assignment is separate from specialization assignment and lesson completion.
- Team membership derives its educational role from the active canonical specialization.
- A one-member team represents `INDIVIDUAL_INTEGRATED_MODE`.
- Submission acceptance never creates a competency or program-completion fact.
- Technical Operations activities are simulation-only and do not grant production authority.
- No program completion, credential, readiness score, employer visibility, or capstone activation is created.

## Lineage

`Program -> Grade 12 Eligibility -> Specialization Assignment -> Course Assignment -> Lesson Completion -> Activity Result -> Evidence -> Authorized Review -> Competency Decision`

Project work is separately owned by:

`Project -> Team -> Membership -> Submission Version`
