# Post-Lock Cross-Product Composition Authority

Migration 112 establishes trusted composition definitions without granting Shared Reporting direct universal query access. Each definition is scoped, versioned, hashed, lifecycle-managed, and contains explicit source projection contracts plus subject, classification, period, and provenance policies.

Definitions accept only registered product keys and projection families. They reject arbitrary evaluators, formulas, and unknown sources. Activation and retirement use existing organization administration permissions. Source facts remain owned by their product adapters.

The composition registry is not itself a cross-product truth authority. Source-by-source authorization, canonical subject linking, period reconciliation, duplicate-fact identity, and a formally approved ecosystem product/report identity are prerequisites before cross-product report families are activated.
