# GEO-1B Implementation Waves

## Wave 1: Contracts and Registries

Create shared contract types, coordinate-space registry, layer registry, and validation tests.

## Wave 2: Selection and Interaction

Implement shared selection lifecycle, interaction envelopes, subscriptions, URL/query sync, and accessibility equivalents.

## Wave 3: Projection Boundary and State

Implement public/private filtering, provenance carry-through, temporal projection, and presentation-state calculation.

## Wave 4: Pilot Client

Connect Metaverse Quick Map as the first read-only Spatial Engine client while preserving all current Metaverse authority boundaries.

## Wave 5: Existing Map Regression Harness

Add regression tests for Exchange / Capital, SHS operational map behavior, SHF Public Impact route expectations, and disconnected preservation candidates before migration decisions.

## Wave 6: Additional Clients

Evaluate Exchange / Capital and SHS operational maps after token, remote-source, and source-authority questions are resolved.

## Wave 7: Evidence and Temporal Intelligence

Add richer evidence, verification, freshness, and temporal overlays after GEO-5 decisions.

## Wave 8: Geographic Command Center

Begin only after GEO-2 through GEO-8 acceptance and GEO-9 implementation planning.
