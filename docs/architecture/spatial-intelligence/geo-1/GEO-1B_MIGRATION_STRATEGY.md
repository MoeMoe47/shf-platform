# GEO-1B Migration Strategy

Migration must be preservation-first. No big-bang rewrite.

## Order

1. shared contracts
2. shared registries
3. read-only adapters
4. selection
5. layer/state projection
6. one pilot map
7. additional restored maps
8. Metaverse Quick Map
9. broader ecosystem clients

## Safest Pilot Surface

Metaverse Quick Map is the safest first client candidate because it is already a visual projection client, can stay in METAVERSE coordinates, and does not require public real-world publication or Mapbox token policy. The pilot must keep Quick Map separate from destination, traffic, mission, event, and emergency authority.

## Non-Goals

Do not migrate maps, restore routes, fix SHF Public Impact, change Mapbox configuration, change coordinates, or build a Geographic Command Center during GEO-1B.
