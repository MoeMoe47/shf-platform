# GEO-1B Provenance Model Plan

Every projected feature should carry provenance sufficient to explain where the claim came from and whether it is eligible for display.

## Required Provenance

- source authority
- source record ID
- evidence reference
- verification state
- publication state
- timestamp
- freshness
- coordinate provenance
- projection adapter identity
- projection version

## Projection Versioning

Projection version should change when adapter logic, coordinate-space interpretation, publication filtering, or state-calculation rules change.

## Display Rule

Spatial displays provenance and verification metadata. Truth, evidence, reporting, and domain systems remain authoritative.
