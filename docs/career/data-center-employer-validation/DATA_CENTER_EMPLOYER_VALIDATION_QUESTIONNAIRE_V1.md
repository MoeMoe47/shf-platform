# Data Center & AI Infrastructure — Employer Validation Questionnaire v1

Please read the [Employer Validation Package](./DATA_CENTER_EMPLOYER_VALIDATION_PACKAGE_V1.md) before completing this questionnaire. For each item, mark **YES**, **PARTIAL**, **NO**, or **N/A**, and use the comment field freely — comments are often more useful to SHF than the rating itself.

The core question behind every section is: **does this reflect real work?** — not simply "is this a good course?"

This questionnaire has two parts. **Complete Part 1 (Core Employer Review)** — that alone is sufficient for a credible review. **Part 2 (Optional Deep Technical Review)** is for reviewers with the additional time and hands-on technical expertise to go further; it is not required.

**Important:** completing this questionnaire — even Part 1 in full — records your review. It does **not**, by itself, produce an "Employer Validated" outcome. See [the Validation Record](./DATA_CENTER_EMPLOYER_VALIDATION_RECORD_V1.json) and the Validation Decision Rule in the main package for what validation actually requires.
