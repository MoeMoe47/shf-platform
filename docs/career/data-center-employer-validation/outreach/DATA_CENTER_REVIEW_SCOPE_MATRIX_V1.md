# Data Center & AI Infrastructure — Review Scope Matrix v1

No reviewer should be asked to review everything. This matrix maps each Tier 1 candidate to the specific [package](../DATA_CENTER_EMPLOYER_VALIDATION_PACKAGE_V1.md) sections and [questionnaire](../DATA_CENTER_EMPLOYER_VALIDATION_QUESTIONNAIRE_V1.md) parts most relevant to their actual expertise, so their time is spent where their perspective is most valuable.

## By Category (general pattern)

| Category | Primary emphasis |
|---|---|
| Data Center Operator | Target roles, operations, monitoring, troubleshooting, safety, access/security, evidence, hiring relevance |
| Infrastructure / Facilities / Technical | Power, cooling, equipment, tools, physical safety, maintenance, escalation, worksite realism |
| Workforce / Education | Curriculum progression, transition pathways, credentials, apprenticeship/training alignment, age-appropriateness, work-based-learning structure |

## Cross-Cutting Rule

Every reviewer, regardless of category, should still see Questionnaire Section K (Overall Review Outcome) and, where the program serves minors, Section E3-E8 (Minor/Student Safety) — these are the two areas SHF needs input from every perspective, not just the specialists. No reviewer should be asked to complete every Optional Deep Technical section; the table above narrows each candidate to 1-3 sections that match their actual expertise.
