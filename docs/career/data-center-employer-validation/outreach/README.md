# Data Center & AI Infrastructure — Outreach Materials

Outreach-preparation artifacts for the Data Center & AI Infrastructure Employer Validation Package, built in Career Pathway Standard Phases 3 and 4. **Nothing in this folder has been sent to anyone, and no organization has been contacted.** Phase 4 researched and named real, publicly-documented Central Ohio candidate organizations (see the files below) — but researching and naming a candidate is not outreach, engagement, or a relationship. No CRM or contact record exists anywhere in this repository, and no organization named in this folder has any relationship with SHF beyond the publicly-cited evidence.

**Current pathway status: PREPARE. Current validation status: NOT REVIEWED.** These materials exist to prepare for outreach, not to represent that outreach has occurred.

## Wave 1 Owner Send Review (Phase 5A) + Contact Routing (Phase 5B)

[`DATA_CENTER_WAVE1_OWNER_SEND_REVIEW_V1.md`](./DATA_CENTER_WAVE1_OWNER_SEND_REVIEW_V1.md) consolidates the exact personalized email, cover letter, and review-scope language for all three Wave 1 organizations into a single document, with freshly re-verified (September 2026) contact routes and an explicit PENDING decision field per organization (APPROVE TO SEND / APPROVE WITH EDITS / HOLD / REJECT). **This is the document to hand an owner for the actual send decision** — the individual files in `wave1/` remain the source drafts.

[`DATA_CENTER_WAVE1_CONTACT_ROUTING_V1.md`](./DATA_CENTER_WAVE1_CONTACT_ROUTING_V1.md) (Phase 5B) goes one level deeper: it identifies the best specific publicly-listed contact route per organization, including named individuals where an official source confirms one (e.g., QTS's Chief External Affairs Officer, IBEW 683's Business Manager), each with a stated confidence level and caveats. No organization has been contacted, and no named individual was included without a stated confidence level and source.

## What this folder is not

Not a contact list, not a CRM, not evidence of any employer relationship, and not a partnership record. Every template here is a **draft requiring a real recipient and explicit owner approval before use** — each file says so individually.

## Relationship to the rest of the package

These materials point back to, and must never restate more loosely than, the actual [Employer Validation Package](../DATA_CENTER_EMPLOYER_VALIDATION_PACKAGE_V1.md), [Questionnaire](../DATA_CENTER_EMPLOYER_VALIDATION_QUESTIONNAIRE_V1.md), and the validation sufficiency rule in [`DATA_CENTER_EMPLOYER_VALIDATION_RECORD_V1.json`](../DATA_CENTER_EMPLOYER_VALIDATION_RECORD_V1.json). If those source documents change, these outreach materials should be re-checked for consistency before use.

## Before actual outreach begins

1. An SHF owner reviews and approves the outreach materials (email, cover letter, brief).
2. An SHF owner reviews and approves, modifies, or rejects individual candidates in the [Final Owner Decision Table](./DATA_CENTER_FIRST_COHORT_PRIORITY_LIST_V1.md#final-owner-decision-table) — Phase 4 researched and proposed candidates, but did not and cannot approve them.
3. The parent folder's [`OUTREACH_READINESS_CHECKLIST_V1.md`](../OUTREACH_READINESS_CHECKLIST_V1.md) is updated to mark "Contact/outreach material ready" as ready.
4. Only then does anyone actually send anything — no step in this repository's history has done that yet.
