# Daily Governance Audits

This folder is reserved for dated daily governance audit reports.

Use this naming convention:

- `DAILY_GOVERNANCE_AUDIT_YYYY_MM_DD.md`
- `DAILY_GOVERNANCE_AUDIT_YYYY_MM_DD.json`

Do not place secrets, real `ADMIN_API_KEY` values, runtime logs, local persistence files, screenshots containing private data, or public-unapproved SHS operational data in daily audit reports.
