# Governed AI Acceptance Plan

## Functional Scenarios

Test Program, Provider, Funding, Metric/Truth, Claim readiness, Reconciliation, Finding, and Audit briefings. Each answer must expose authorized canonical references and distinguish facts, analysis, and recommendations.

## Security Scenarios

Test cross-tenant and wrong-purpose denial, classification ceilings, Investigation denial, prompt injection, bounded context, tool allowlists, provenance, and human approval for high-impact recommendations.

## Frozen Boundary

AI remains advisory. It cannot create Truth, raise Verification, verify itself, resolve Reconciliation, merge entities, issue or resolve Findings, approve Corrective Action, determine fraud, create Recovery, impose sanctions, create final Decisions, or publish restricted data.
