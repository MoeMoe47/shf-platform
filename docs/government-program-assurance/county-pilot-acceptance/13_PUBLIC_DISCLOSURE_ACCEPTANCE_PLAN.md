# Public Disclosure Acceptance Plan

Test an accepted internal Truth, a `PUBLIC_APPROVED` Truth, and a restricted Truth. Verify that only Public Disclosure-approved records appear in public views or reports.

| Test | Expected result | Evidence | Status |
|---|---|---|---|
| Internal Truth only | Not public | Endpoint/UI evidence | NOT_STARTED |
| Public-approved Truth | Public-safe projection only | Endpoint/UI evidence | NOT_STARTED |
| Restricted Truth | Denied/redacted | Endpoint/UI evidence | NOT_STARTED |
| Supersession/revocation | Prior public record is bounded appropriately | Event/report evidence | NOT_STARTED |

Truth acceptance does not equal public approval.
