# Real Data Onboarding Plan

| Stage | Data boundary | Promotion gate | Status |
|---|---|---|---|
| 0 | Synthetic fixture only | Environment and controls verified | READY |
| 1 | Schema/sample validation | Source owner, mapping, policy, classification approved | NOT_STARTED |
| 2 | Redacted or limited county data | Security and quality review passed | NOT_STARTED |
| 3 | Controlled UAT data | UAT participants and rollback approved | NOT_STARTED |
| 4 | Approved production pilot data | GO checklist approved by authorized owners | NOT_STARTED |

No real data is connected in Phase 0.
