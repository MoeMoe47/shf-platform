# User Lifecycle Plan

1. Request with organization, tenant, persona, Program/Provider scope, and classification need.
2. Obtain county owner approval and verify legal/security prerequisites.
3. Provision the minimum canonical role and require MFA.
4. Activate only after allowed/denied access tests pass.
5. Review access periodically and on scope changes.
6. Record temporary elevation with expiry and approval.
7. Suspend or revoke promptly on role change, incident, expiry, or termination.
8. Retain provisioning, review, and revocation evidence according to approved policy.

No indefinite orphaned access is permitted.
