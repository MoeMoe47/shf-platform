# User Provisioning Runbook

For each approved real user:

1. Validate county approval and identity.
2. Resolve canonical Organization/Tenant.
3. Assign the minimum canonical role.
4. Assign Program/Provider scope.
5. Set classification ceiling.
6. Require and verify MFA.
7. Activate the account.
8. Verify allowed access and direct-route denial.
9. Record actor, scope, timestamp, approval, and evidence.
10. Assign review and revocation dates.

No real user is provisioned by this runbook now.
