# Legal-to-Technical Authority Map

This map extends existing authorities only. It does not design a Legal Registry, schema, API or runtime enforcement. Legal status is not inferred from a role, permission, relationship, UI state, seed record or hash.

## Canonical authentication paths

The verified technical controls are located under `apps/shs-api/src/auth/`:

- `apps/shs-api/src/auth/auth-middleware.ts` establishes technical authenticated identity.
- `apps/shs-api/src/auth/organization-context.ts` establishes technical organization and tenant scope.
- `apps/shs-api/src/auth/permission-guard.ts` establishes application authorization.

None of these controls establishes legal signing authority, board authority, fiduciary authority, agreement execution or legal ownership. Earlier `apps/shs-api/src/middleware/` references are noncanonical for these three controls and must not be used.
