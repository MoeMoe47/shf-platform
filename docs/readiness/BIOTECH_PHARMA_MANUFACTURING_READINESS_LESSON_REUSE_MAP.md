## 4. Important Non-Equivalence Rule

Similarity in vocabulary does not establish biotechnology or pharmaceutical authority.

For example:

- generic documentation is not GMP documentation authority
- generic controlled change is not pharmaceutical change-control authority
- Data Center environmental monitoring is not cleanroom environmental-monitoring authority
- semiconductor contamination awareness is not aseptic-processing authority
- generic traceability is not pharmaceutical material / batch traceability authority
- generic quality language is not QA / QC authority

Domain-specific equivalence requires evidence and review.
