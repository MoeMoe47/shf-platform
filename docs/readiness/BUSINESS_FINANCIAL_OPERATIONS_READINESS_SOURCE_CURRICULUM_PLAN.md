## 35. REUSE Interpretation

REUSE means an existing canonical UCR lesson already provides substantially equivalent learning content.

The Business course should reference or compose that content rather than recreate it.

## 36. CONTEXTUALIZE Interpretation

CONTEXTUALIZE means the universal learning objective already exists but requires Business-specific examples, terminology, scenarios, or records.

Contextualization must not create duplicate universal competency authority.

## 37. EXTEND Interpretation

EXTEND means the repository contains a useful canonical capability or learning foundation but Business requires additional source curriculum to cover the operational context.

## 38. MISSING Interpretation

MISSING means targeted discovery did not prove functionally equivalent source curriculum.

It authorizes planning for source curriculum.

It does not automatically authorize:

- competency creation
- proof configuration
- schema changes
- migrations
- new domain services
- new authority
