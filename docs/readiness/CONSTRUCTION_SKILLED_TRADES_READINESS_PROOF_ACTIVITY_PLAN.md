## 2. Canonical Evidence Authority

Construction must use the existing Prepare / Prove and verified-evidence architecture.

The governing chain remains:

Activity Result
→ Evidence
→ Authorized Review
→ Competency Decision

A lesson completion is not verified competency.

A simulation result is not verified competency.

A Metaverse result is not verified competency.

An Arcade result is not verified competency.

An AI output is not verified competency.

A submitted construction artifact is not automatically verified competency.

## 3. Proof Density Principle

The proposed course contains 75 lessons.

It should not contain 75 formal competency proofs.

Most lessons are intended to:

- orient
- teach
- contextualize
- practice
- assess understanding
- produce evidence candidates
- support reflection

Formal proof should be limited to a small number of synthesis activities.

## 5. Proof Classification Model

Each proof candidate must be classified as:

### REUSE

Existing competency and proof configuration are functionally equivalent.

### CONTEXTUALIZE

Existing authority is reusable, but construction-specific prompts or scenarios are required.

### EXTEND

Existing capability is close, but the current proof shape is insufficient.

### NEW CANDIDATE

No functionally equivalent proof or competency is found after audit.

No new competency ID may be invented in this document.

## 7. Safety / Scope — Target Capability

The learner should demonstrate the ability to:

- recognize a potential construction hazard
- distinguish facts from assumptions
- identify the limits of their role and authorization
- stop when conditions are unsafe or unclear
- avoid improvising outside scope
- identify an appropriate escalation path
- communicate the concern accurately
- preserve uncertainty
- avoid representing readiness as qualification

This is workplace safety and scope awareness.

It is not trade authorization.

## 12. Safety / Scope — Safety Boundary

The proof must not require learners to:

- work at height
- climb ladders or scaffolds
- operate power tools
- operate heavy equipment
- enter confined spaces
- perform energized electrical work
- open electrical panels
- handle refrigerants
- service HVAC equipment
- perform plumbing installation
- perform structural modification
- override site controls
- conduct hazardous live field tasks

All scenarios must remain synthetic, simulated, classroom-safe, or otherwise explicitly governed.

## 13. Safety / Scope — Pass / Revise Intent

- recognizes the concern
- avoids unsafe action

- stays within scope
- chooses a reasonable escalation path
- communicates accurately

Potential revise conditions include:

- unsafe action selected
- authorization boundary ignored
- unsupported assumption treated as fact
- escalation omitted
- trade authority overstated

Canonical criteria remain unresolved.

## 17. Problem-Solving / Quality — Target Capability

The learner should demonstrate the ability to:

- define a construction problem
- distinguish facts from assumptions
- use supplied evidence
- identify relevant plans, requirements or specifications
- compare possible causes

- compare response options

It is not design authority.

## 22. Problem-Solving / Quality — Design Boundary

The proof may ask the learner to interpret simplified synthetic construction information.

- approve a field change

- stamp a plan
- act as architect or engineer
- direct structural correction
- override a specification

## 23. Problem-Solving / Quality — Inspection Boundary

The proof may ask whether supplied synthetic work appears inconsistent with a supplied requirement.

- approve work

- issue code findings
- sign inspection records
- complete official punch-list acceptance
- approve final completion

## 24. Problem-Solving / Quality — Measurement Boundary

If measurements are used:

- no hazardous live measurement is required
- no survey authority is implied
- no field-layout qualification is implied
- no inspection qualification is implied

## 25. Problem-Solving / Quality — Electrical Boundary

If an electrical issue appears:

- use supplied diagrams or synthetic values

The learner must not:

- open panels
- wire circuits
- probe live systems
- perform electrical repair
- approve electrical work

## 26. Problem-Solving / Quality — HVAC Boundary

If an HVAC issue appears:

- use synthetic airflow, thermal or equipment information
- reuse canonical HVAC reasoning
- preserve safe escalation

The learner must not:

- handle refrigerants
- repair equipment
- modify controls
- commission systems
- approve HVAC installation

## 43. Functional Equivalence Gate

Before any new Construction competency or proof configuration is proposed, implementation must answer:

1. Does UCR already describe the capability?
2. Does electrical infrastructure already describe it?
3. Does mechanical/HVAC already describe it?
4. Can construction context be passed as configuration or scenario?
5. Can an existing proof accept construction evidence?
6. Is the learner capability genuinely different?
7. Who owns the capability canonically?
8. Who may review the evidence?
9. Is a new authority actually necessary?

If existing capability is functionally equivalent, reuse is mandatory.
