## 5. Classification Meaning

### REUSE

Existing source / competency / proof authority is sufficiently equivalent that Energy should reuse it rather than create a second capability.

### CONTEXTUALIZE

Existing transferable or technical authority exists, but Energy / Utility context must be added around it.

### EXTEND

A canonical capability exists, but the utility application adds a materially new domain context or evidence shape.

### MISSING

Repository review did not prove sufficiently equivalent governed source curriculum.

MISSING does not automatically authorize:

- a new competency
- a new registry
- a new proof engine
- a database migration

## 7. Non-Equivalence Rule

Shared terminology does not establish functional equivalence.

Examples:

- facility distribution is not automatically utility distribution
- data-center telemetry is not utility SCADA authority
- electrical incident analysis is not grid-operator authority
- critical-power reliability is not bulk-grid balancing authority
- generic monitoring is not water-treatment authority
- renewable references are not a governed renewable-energy curriculum
