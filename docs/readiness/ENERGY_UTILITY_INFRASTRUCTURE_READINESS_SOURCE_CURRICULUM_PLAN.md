## 6. Lesson Classification Model

Each lesson is conceptually classified as:

### TRANSFERABLE

The capability should primarily reuse Universal Career Readiness.

### CANONICAL-ELECTRICAL

The capability should primarily reuse the existing `electrical-infrastructure` technical domain.

### CONTEXTUALIZED

Canonical capability exists but requires energy / utility / public-works context.

### INDUSTRY-SPECIFIC

The concept is substantially utility, grid, renewable, water, wastewater, or public-works specific.

Final REUSE / CONTEXTUALIZE / EXTEND / MISSING decisions belong in Artifact 2.
