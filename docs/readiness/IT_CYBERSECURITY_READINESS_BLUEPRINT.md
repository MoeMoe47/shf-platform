# IT & Cybersecurity Readiness — Course Blueprint

Status: DRAFT — PARALLEL PASS 1
Branch: agent/readiness-cybersecurity
Baseline: 518dda1
Stable key: `shu-it-cybersecurity-readiness`

## 1. Course Purpose

Prepare learners to understand IT support, networking, systems, and defensive cybersecurity workplaces; develop safe troubleshooting habits; work within authorization boundaries; document technical evidence; support users; and make informed next-step career decisions.

This course is readiness education.

It does not independently confer certification, production access, administrative authority, security clearance, or professional incident-response authority.

## 2. Intended Audience

Primary audiences may include:

- secondary students
- youth workforce participants
- adult career changers
- learners exploring IT support
- learners exploring networking
- learners exploring system administration
- learners exploring cybersecurity
- learners exploring SOC roles
- learners preparing for external IT or cybersecurity training

## 3. Architectural Position

Universal Career Readiness
→ IT & Cybersecurity Readiness
→ reuse of canonical technical operations / networking / cybersecurity capabilities
→ career-specific preparation
→ external training / certification where applicable
→ employment

This course owns the cross-industry readiness and contextualization layer only.

## 14. Cyber Safety Boundary

The course must remain defensive and authorized.

Allowed:

- synthetic systems
- disposable sandboxes
- mock logs
- simulated incidents
- defensive configuration reasoning
- documentation
- analysis
- escalation

Not authorized:

- real-world unauthorized scanning
- exploitation
- credential attacks
- malware deployment
- privilege escalation
- bypassing access controls
- traffic interception
- evasion
- destructive actions
- production access without explicit authorization

## 15. Certification Boundary
