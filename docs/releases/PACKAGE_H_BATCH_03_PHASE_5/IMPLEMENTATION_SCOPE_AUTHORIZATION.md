# Implementation Scope Authorization

`ISA-1` authorizes only `IGLS-1 Phase 6 - GOVERNED_IMPLEMENTATION`.

The authorized implementation scope is limited to `B03-CAP-001` through `B03-CAP-004`, with required traceability to CTB-1, BDL-1, IRS-1, ACS-1, EM-1, EPL-1, GLS-1, IAG-1, and GFM-1.

Deployment, publication, production release, architecture redesign, new layers, new registries, duplicate evidence authority, duplicate runtime ownership, and implementation outside the four locked capabilities remain prohibited.
