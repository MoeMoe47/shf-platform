# Buyer Types

Canonical buyer categories supported by evidence or plausible adjacency:

| Buyer category | Candidate fit |
|---|---|
| K-12 schools / districts / charter / private schools | Curriculum, Data Center, Arcade, Metaverse, Career Center, Studio, accessibility, reporting. |
| Colleges / universities / career-tech organizations | Data Center, Career Center, Studio, credentials, reporting, employer validation. |
| Workforce boards / American Job Centers | Career pathways, employer incentive intelligence, WBL support, reporting. |
| Municipalities / counties / state agencies | CivicSure, assurance, reporting, civic simulations, infrastructure simulations. |
| Nonprofits / community organizations | SHF programs only after operating model; reporting, evidence readiness, web builder. |
| Youth / after-school / summer / libraries | Camps, Learning Arcade, civic/financial capability, Metaverse access. |
| Employers / enterprise businesses | Data Center validation, WBL/employer engagement, Agent Fabric, Studio/Web Builder, Metaverse sponsorship/custom. |
| Data center operators | Data Center pathway validation/sponsorship, workforce pipeline support after review. |
| Healthcare employers / hospitals / nursing facilities | Fixture concepts only; not sellable without regulated partner authority. |
| Fire departments / public-safety agencies | No found offering. |
| Utilities / contractors / infrastructure employers | Infrastructure simulation concepts only. |
| Logistics employers / unions / apprenticeship sponsors | Logistics concepts and WBL framework only; needs partner authority. |
| Banks / credit unions / foundations / philanthropy | Civic/financial capability sponsorship, scholarships, reporting/evidence packages. |
| Training providers | Curriculum/platform, Career Center, Studio, Reporting, Evidence. |
| Government agencies | CivicSure, Trusted Reporting, Agent Fabric/assessments subject to procurement/security review. |

The registry must map buyers per product. No offering should default to all buyers.
