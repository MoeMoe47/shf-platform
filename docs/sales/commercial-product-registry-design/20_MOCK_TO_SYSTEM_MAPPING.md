# Mock To System Mapping

This file maps the latest approved Commercial Product Registry mock to the future Sales read model. The mock is visual direction only, not production data. It uses the approved SHF Sales App shell: white/light institutional workspace, navy typography, blue primary controls, left Sales navigation, Products expanded, Commercial Registry selected, realistic desktop proportions, compact rounded cards, status pills, and a simple guided workflow.

The UI must never fabricate counts, readiness, sellability, prices, margin, commission eligibility, funding eligibility, review approvals, renewal, expansion, or source verification.
