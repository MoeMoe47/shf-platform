# Audit Evidence Packet

Evidence packet contents for each controlled activation:

- Dry-run output.
- Operator Identity user id.
- Reviewer Identity user id.
- Organization id.
- Membership id.
- Required capability.
- Candidate id and commercial product id.
- Gate assignment.
- `effective_at` and `expires_at`.
- Assignment id.
- Queue visibility proof.
- Decision id when a real human submits manually.
- Source resolution id when applicable.
- Audit event ids for assignment creation, decision/source resolution, and revocation.
- Reassessment output.
- Proof unrelated candidates and gates are hidden.
- Proof no production onboarding rows or lifecycle/readiness/sellability mutations occurred.

Public documentation must not contain personal emails, credentials, session tokens, or plaintext secrets.
