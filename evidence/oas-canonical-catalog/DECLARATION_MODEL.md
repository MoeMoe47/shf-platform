# Declaration model

OAS defines the shape; an external provider/system authors the assertion; Registry may later record it under Registry's own authority. No declaration is populated in the public catalog. Schema version 1.0.0 includes standard_reference with exact standard/version/release pin, optional profile_reference (null if none), requirement_references, declaration_scope, declared_by, declared_at, declaration_status (declared/withdrawn), evidence_references, notes and evaluation_status fixed to NOT_EVALUATED. No identity/authentication proof is implemented by a declared_by string. Evidence references are references, not evidence verification or fetching instructions.

A requirement is an OAS-authored normative obligation. A declaration is an attributed provider statement about scoped references. Evaluation is a defined comparison against criteria and evidence; none is supplied here. An assessment is an independent interpretive judgment, including Trust Bureau's separate authority. Certification would require an explicitly governed scheme and authorized issuer; no such OAS certification scheme is implemented or implied. Schema validity, report generation, registration and declaration do not create conformance.

Use validateDeclaration after validating the referenced catalog: shape-only JSON Schema cannot resolve cross-document existence. It rejects unknown/mismatched release, profile and requirement references. Empty catalogs prohibit fictional requirement/profile claims. A standard-only draft reference declaration remains NOT_EVALUATED. Withdrawn declarations remain historically attributable. Historical supersession observations never rewrite the provider's pinned scope/time/refs. Registry later chooses authenticated recording and privacy/public projection in its own phase; no Registry service is added here.
