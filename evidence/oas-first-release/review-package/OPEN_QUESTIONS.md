# Open questions

## Q01 — Actor and applicability

Status: open. Scope: all.

Approve whether this first set governs provider description records only, or must also specify runtime behavior. All candidates explicitly target description records; no runtime efficacy follows.

## Q02 — Risk applicability

Status: open. Scope: risk model.

Define R0–R4 assignment criteria, decision authority, reassessment and conflict rules before risk-conditioned obligations.

## Q03 — Ownership

Status: open. Scope: OAS-1-REQ-0001.

Clarify accountable owner versus legal ownership, multiple owners, and acceptable organization identifiers.

## Q04 — Provenance

Status: open. Scope: OAS-1-REQ-0002.

Approve minimum provenance granularity and treatment of composite, externally hosted or continuously updated systems.

## Q05 — Permissions and capability completeness

Status: open. Scope: OAS-1-REQ-0006–0009.

Approve scope boundaries, dynamically discovered tools, permission exceptions and whether runtime denial behavior belongs in release 1.

## Q06 — Prohibited actions and guardrails

Status: open. Scope: OAS-1-REQ-0010–0011.

Identify who defines prohibited actions and context-specific policies; decide whether effectiveness criteria are required. No universal legal or safety prohibition list is invented.

## Q07 — Human control

Status: open. Scope: OAS-1-REQ-0012–0013.

Review override feasibility, escalation thresholds, response latency and failure behavior. No unsupported latency or always-on human mandate is authored.

## Q08 — Evidence and verification

Status: open. Scope: OAS-1-REQ-0014–0015.

Review minimum test methods, evidence accessibility, privacy, retention and whether evidence plans alone suffice. No completeness or conformance follows from evidence presence.

## Q09 — Lifecycle

Status: open. Scope: OAS-1-REQ-0016–0017.

Approve lifecycle vocabulary, version identity, retirement responsibilities and record retention; Registry lifecycle remains separate.

## Q10 — Governance approval authority

Status: open. Scope: all.

OAS must identify its authorized adopter, decision procedure/quorum and approval record. None is established by repository code.

## Q11 — Legacy domain mapping

Status: open. Scope: domain mapping.

Review every ambiguous reporting label and approve migration disposition before canonical report adoption.

## Q12 — Release scope adequacy

Status: open. Scope: all.

Decide whether these traceable description obligations constitute a useful complete first standard; no claim of complete autonomous-system governance is made.
