# Release presentation

src/pages/oas/oasRelease.js is the sole website release metadata adapter. It imports the frozen catalog/currentness and derives name, ID, version, date, requirement/domain counts, declaration contract, evaluation status and checksums. It centrally supplies resource URLs. It is presentation configuration, not new normative authority.

Quick facts, shared footer and Standard release summary now present OAS-1@1.0.0 as a frozen published release dated 2026-10-27. Working Draft/Public Review copy was removed from live website text and HTML descriptions. The obsolete draft-labelled book illustration is no longer rendered; its existing image file is unchanged. A restrained text summary occupies the existing hero column. No new artwork was created.

Read OAS 1.0, JSON, currentness and declaration schema are real links on OAS-1. The three public hashes appear in a details disclosure. The artifact file hash comes from currentness; the catalog's internal artifact_checksum describes a different payload hash and is not misrepresented as the file hash.

Shared boundary copy preserves provider attribution, NOT_EVALUATED and all four authorities. Risk classification is explicitly informative and cannot certify, assess or authorize deployment. Detailed legacy overview/TOC/scope alignment remains Batch 2 work, not a claim that every page is release-complete.
